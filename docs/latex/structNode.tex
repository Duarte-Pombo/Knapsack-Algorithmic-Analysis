\doxysubsection{Detailed Description}
Represents a node in the decision tree for the branch and bound algorithm. 

Each node stores the current level in the tree, total weight and profit of selected pallets, the number of pallets used, the sum of their IDs (for tie-\/breaking), the path taken, and a bound on the maximum profit achievable from this node.
